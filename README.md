# MOVIEAPP CON API REST

Esta es una página para obtener información de las películas en tendencia usando la Api de TheMovieDB.

Cuenta con un menu para ir navegando entre las distintas páginas, permitiendo clasificar las películas en tendencia entre populares, por género, entre otros.

Además, se puede ver la información individual de las películas, como la reseña, calificación, poster, trailer, cast, entre otros.

Es uno de mis últimos proyectos, el cual lo sigo actualizando para implementar mejoras.

## CARACTERÍSTICAS

### CONSTRUIDO CON

- HTML semántico
- Css
- JavaScript
- Api Rest

### API REST

Se hicieron pedidos a la api de TheMovieDb para obtener información de las películas en tendencia.

### DISEÑO RESPONSIVO

El diseño se adapta a distintos dispositivos, agregando un menú plegable en mobile y ajustando tamaños en dispositivos más grandes.

### LAZY LOADING

Se usó lazy loading para mejorar la optimización de la página, así como ahorrar recursos en imágenes que aún no se visualizan.

### INFINITE SCROLL

Se aplicó infinite scroll mediante intersection observer para que pueda cargarse información de manera continua e ininterrumpida.

### DISEÑO MODULAR

Se implementaron diversas funciones reutilizables para que pueda agregarse más contenido de forma facil y sencilla, así como facilitar la actualización.
